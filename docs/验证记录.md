# 验证记录

## 2026-10-24：模型输出流式传输

`CompatibleModel` 新增可选 `on_delta` 回调：配置后改用 `stream=True` 的 OpenAI 兼容 SSE 请求，逐段解析 `delta.content`，按 0.2 秒或 240 字符节流发射 `model_output` 事件（含 step 与序号），usage 从末尾 usage 块提取；流结束后对累积全文走原有 JSON 决策解析与 FormatError 反馈路径。流中断重试前会发送清空标记（`delta=null`），避免重复增量拼接；不配置回调时保持原同步 JSON POST 路径，既有协议测试不受影响。

服务端把增量经既有事件通道（SQLite 事件表 → SSE 游标）透传，工作台时间线新增流式输出气泡，`action`/`format_error` 事件到达时定稿移除。新增两条协议测试覆盖流式累积、usage 提取与断流重试清空。vendor 循环零改动——流式完全收敛在模型对象内部。
