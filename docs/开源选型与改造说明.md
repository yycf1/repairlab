# 开源选型与改造说明

## 选型

| 候选 | 参考价值 | 本次取舍 |
| --- | --- | --- |
| [mini-swe-agent](https://github.com/SWE-agent/mini-swe-agent) | 核心循环小，模型和环境可替换，便于逐步读懂 | 选作基础，固定版本，只保留必要循环及工具函数 |
| [SWE-agent](https://github.com/SWE-agent/SWE-agent) | 软件修复领域的成熟项目，可以继续学习其工具和评测设计 | 本次不引入完整运行体系，控制首版学习及部署成本 |
| [OpenHands software-agent-sdk](https://github.com/OpenHands/software-agent-sdk) | SDK 路线，可以参考更完整的运行时和扩展方式 | 用于对比学习，当前重点是自己能复述和重建关键链路 |

这个取舍针对个人项目的实现成本，不代表另外两个项目能力不足。可复现依据为 `source.json` 中的具体 commit，而非随时变化的上游主分支。

## 真实复用范围

`RepairAgent` 继承 vendored `DefaultAgent`，实际执行其 `run → step → query → execute_actions` 循环。保留消息维护、异常控制流及序列化工具；迁移三处模块导入，加入本地结构契约。未执行上游包的全局 dotenv 读取、用户目录初始化和启动宣传。

`scripts/fetch_upstream.py` 记录获取来源，拒绝覆盖已有来源文件；升级需先审查变更。不能将本项目称为全栈从零原创，也不能将上游 benchmark 成绩写成自己的成绩。

## 新增内容

| 模块 | 本地职责 | 面试讨论点 |
| --- | --- | --- |
| Model adapter | JSON 动作、校验、格式错误反馈、usage、上下文裁剪 | 如何处理模型输出不稳定 |
| Tool environment | 搜索、阅读、AST 定位、局部编辑、固定测试、计划 | 模型决策与宿主执行权限如何分离 |
| Repository guard | 快照、路径边界、编辑白名单、测试保护 | 防止修改断言或配置制造通过 |
| Runner | 超时、进程清理、输出上限、可选容器 | 执行约束不能仅依赖提示词 |
| Verifier | 干净副本应用补丁，验收和回归 | submit 是候选结果，不能自证成功 |
| Service / Store / UI | 后台任务、取消、SQLite、SSE、轨迹和下载 | 运行过程可检查、可追查 |
| Examples / evaluation | 自建缺陷和外置验收集，反馈机制对照 | 区分脚本教学和模型实测 |
